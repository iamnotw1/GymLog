# GymLog

A modern Android workout logging application designed for strength training and fitness tracking. Built to provide a clean, intuitive, and completely offline experience for managing workout routines and progress.

## Features

* **Workout Tracking:** Easily log daily routines, exercises, sets, reps, and weights.
* **Offline First:** Complete local data management ensuring your fitness data is accessible without an internet connection.
* **Modern UI:** A highly responsive and declarative user interface built with Jetpack Compose.

## Tech Stack & Architecture

This project is built with modern Android development practices in mind:

* **Language:** Kotlin
* **UI Toolkit:** Jetpack Compose
* **Architecture:** MVVM (Model-View-ViewModel) with State Lifting
* **Local Storage:** Room Database for robust data persistence
* **Asynchronous Programming:** Kotlin Coroutines

## Getting Started

To run this project locally on your machine, follow these steps:

### Prerequisites
* Android Studio (Latest stable version recommended)
* Android SDK 

### Installation

1. Clone this repository to your local machine:
   ```bash
   git clone [https://github.com/YourUsername/GymLog.git](https://github.com/YourUsername/GymLog.git)

2. Open Android Studio and select Open an existing project.

3. Navigate to the cloned directory and select it.

4. Allow Android Studio to sync the project with Gradle files.

5. Click the Run button to build and launch the app on your connected device or emulator.
